Methodology

01 Periodic feature extraction in TaXer

A TimesNet-style extractor uses FFT to identify dominant periods. It reorganizes the history into period-aligned representations and uses two-dimensional convolution to model variation within and across periods.

Temporal prior
Represent repeated structure explicitly before transformer fusion.
Feature output
Pass temporal feature vectors to a learned projection layer.

Sources: Feature extraction and projection · Cross-attention interface

02 Feature-level fusion through cross-attention

A linear projection matches the extractor output to the transformer embedding dimension. Variable-wise patch embeddings and a global token encode the original sequence; the extracted features provide cross-attention context.

Shared context
Broadcast the projected features across variables while preserving the model’s tensor-shape contract.
Learned interaction
Allow the sequence representation to query the temporal features inside the model, instead of averaging independent forecasts.

temporal features → linear projection → cross-attention context

Sources: Feature extraction and projection · Cross-attention interface

03 Convolutional comparison and output reconstruction

WaXer replaces the periodic feature extractor with WaveNet-style dilated causal convolutions while retaining the projection and transformer integration pattern.

Alternative prior
Compare explicit periodic structure with a convolutional receptive field.
Forecast output
Normalize the sequence per variable, predict with the transformer head, and restore the original scale for evaluation.

Sources: WaveNet–transformer integration

Implementation notes & source evidence

The design question

Can a transformer benefit from a feature extractor that explicitly captures temporal structure? The team compared TaXer, which uses TimesNet-style periodic features, with WaXer, which uses WaveNet-style dilated causal convolutions. Weather and Sticker Sales sequences provide different tests of the same integration idea.

Sources: Project setup

Connecting two models at the right interface

TaXer detects dominant periods through FFT-based TimesNet features, then uses a learned linear projection to match the transformer’s embedding dimension. Variable-wise patch embeddings provide the endogenous sequence, while the extracted features are broadcast as cross-attention context. The encoder’s global token queries that context. This is feature-level integration, rather than averaging two independent forecasts.

Sources: Feature extraction and projection · Cross-attention interface

An alternative temporal prior

WaXer replaces the periodic feature extractor with dilated causal convolutions while keeping the projection and transformer integration pattern. The two variants let the team compare explicit periodic structure with a convolutional receptive field. Input/output shapes and per-variable normalization are handled explicitly so forecasts can be returned at the original scale.

Sources: WaveNet–transformer integration

Evaluation and engineering takeaway

The supplied report compares models on global weather, Korean weather, and Sticker Sales, including model-size ablations. Its main Sticker comparison reports TaXer MSE of 0.1569 versus 0.1647 for TimeXer. These are course-project results under the reported setup. The useful engineering question is how representation choice, model capacity, and inference cost interact.

Sources: Team report
