The question

Can explicitly extracting periodic features improve transformer-based forecasting on strongly periodic sequences? We explored this question using weather observations and retail sales data.

Two hybrid architectures

TaXer incorporates a TimesNet-inspired block that identifies dominant periods and extracts features through 2D temporal modeling. WaXer instead uses WaveNet-inspired dilated causal convolutions. In both variants, the extracted features provide context to the transformer through cross-attention.

Evaluation

The course report compares the hybrids against iTransformer and TimeXer across global weather, Korean weather, and Sticker Sales data. In the reported Sticker Sales comparison, TaXer achieved an MSE of 0.1569 versus 0.1647 for TimeXer.
