Time-Series Learning

Period-Aware Time-Series Forecasting

Introduction to Deep Learning · SNU · 2025 · Course Project

Time-series forecasting through transformer cross-attention to FFT-based periodic features or dilated causal convolutional features.

Overview / Methodology / Results / My contribution

Overview

Test temporal feature extractors inside a transformer forecaster. Compare periodic and convolutional representations on weather and sales data.

Methodology

01 TaXer: periodic features

Use TimesNet-style FFT analysis to select dominant periods.

  • Period alignment: Reshape each sequence according to the selected periods.
  • Feature extraction: Apply 2D convolution to model variation within and across periods.

Sources: Feature extraction and projection · Cross-attention interface

02 Transformer integration

Project extracted features into the transformer embedding dimension.

  • Sequence branch: Use variable-wise patch embeddings and a global token.
  • Feature branch: Broadcast projected temporal features across variables.
  • Cross-attention: Let the sequence representation query the feature context.
  • Prediction: Apply the forecast head. Restore each variable’s original scale.

temporal features → linear projection → cross-attention context

Sources: Feature extraction and projection · Cross-attention interface

03 WaXer: convolutional alternative

Replace periodic extraction with WaveNet-style dilated causal convolutions.

  • Shared interface: Keep the projection and transformer integration pattern.
  • Comparison: Evaluate the alternative temporal prior. Compare forecast errors and model sizes.

Sources: WaveNet–transformer integration · Team report
