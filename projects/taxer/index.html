Time-Series Learning

TaXer and WaXer: Time-Series Forecasting

Introduction to Deep Learning · SNU · 2025 · Course Project

Combine a transformer forecaster with periodic or dilated-convolution temporal features.

CodeReportSlides

Motivation

Temporal feature extractors encode different assumptions about a sequence. This course project compares periodic and convolutional features within a transformer forecasting pipeline.

  • TaXer: Use FFT-selected periods and two-dimensional convolution.
  • WaXer: Use dilated causal convolutions as an alternative temporal prior.

My contribution

Team project with Jinwoo Seo, Hyeonseop Shin, and Manyoung Han. The architectures and reported experiments were developed by the team.

Model architecture

1. TaXer: learn temporal context from dominant periods

Pass the input window through a TimesNet feature extractor before the forecasting transformer.

  • Period selection: Use FFT amplitudes to select dominant periods and reshape the sequence into within-period and across-period axes.
  • Temporal features: Apply the TimesNet 2D convolution blocks, then project their output to the transformer embedding dimension.
  • Context sharing: Broadcast the projected temporal context to each variable’s forecasting branch.

2. Global-token cross-attention

Normalize each variable’s input window and split it into patch tokens plus one global token.

  • Patch self-attention: Model relationships among patches within each variable branch.
  • Temporal cross-attention: Use the global token as the query and the projected temporal features as keys and values.
  • Forecast head: Flatten the updated patch/global-token representation and project it to the prediction horizon.
  • Output scale: Restore the input window’s per-variable mean and standard deviation after prediction.

Q = global token; K, V = projected temporal features

The auxiliary context comes from the same input window. It is an extracted representation rather than an additional measured sensor stream.

3. WaXer: replace the temporal prior

Use a WaveNet feature extractor through the same projection and cross-attention interface.

  • Causal convolutions: Increase dilation as 1, 2, 4, … and trim right padding to exclude future samples.
  • Gating: Multiply tanh-filter and sigmoid-gate outputs. Combine residual paths with accumulated skip features.
  • Shared forecaster: Feed these features into the same variable-wise transformer and forecasting head.
