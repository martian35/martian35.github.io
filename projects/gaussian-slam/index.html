Research focus

This project investigates 3D Gaussian Splatting as a scene representation for simultaneous localization and mapping (SLAM). The aim is to connect camera motion estimation with a consistent 3D map of the surrounding environment. The work is ongoing at RPM Robotics Lab.

First-author manuscript in preparation

A first-author manuscript is in preparation. There is currently no public GitHub repository for this research.

How this connects to my current research

This work studies how a 3D representation is built and checked. At AIDAS Lab, I explore the next step: using reconstructed geometry to create robot-learning data.
