Overview

Recover brain and knee MRI images from undersampled multi-coil k-space. K-space contains the frequency-domain measurements. The challenge uses 4× and 8× acceleration.

Methodology

01 Measurement-consistent reconstruction

Feature VarNet and FI VarNet alternate learned updates with data-consistency operations.

  • Coil sensitivities: Estimate sensitivity maps from multi-coil measurements.
  • Reconstruction cascades: Feature VarNet refines feature representations. FI VarNet also includes image-domain cascades.
  • Data consistency: Use the MRI encoding model to keep updates connected to acquired k-space samples.

Sources: Reconstruction models

02 Condition-specific experts

Train separate experts for anatomy and acceleration. Use explicit rules to select them at inference.

  • Anatomy: Identify brain or knee inputs from coil count under the challenge data conventions.
  • Acceleration: Read the sampling mask to select a 4× or 8× model.

Sources: Expert routing and inference

03 Training pipeline

MRI-aware augmentation increases training diversity. AdamW and warmup/cosine scheduling support optimization.

  • Augmentation: Use small rotations, shearing, and horizontal flips. Increase augmentation strength during training.
  • Memory: Use DeepSpeed and activation checkpointing for the reconstruction models.
  • Checkpoints: Resume interrupted runs. Convert distributed checkpoint state into inference weights.

Sources: Training and checkpoint handling · Training strategy

04 Averaging and ensembling

The submission uses both weight averaging and output ensembling.

  • Checkpoint averaging: Average compatible model weights into one checkpoint. This adds no extra model forward pass.
  • Prediction ensemble: Run configured Feature VarNet and FI VarNet pairs. Average their reconstructed images.

Sources: Parameter averaging · Prediction ensembling
