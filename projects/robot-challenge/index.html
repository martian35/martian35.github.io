Overview

The target classes are announced at match time. The robot has 180 seconds to collect and deliver them.

Methodology

01 Robot platform and interfaces

A Jetson Orin Nano runs perception and navigation. An ESP32 controls the four mecanum-wheel motors.

  • Command interface: Body-velocity commands travel over USB serial. The controller converts them into wheel motion.
  • Calibration: Wheel direction and feed-forward gains are calibrated. Motion commands include a duration and auto-stop.

Sources: Motor interface and calibration

02 Dual-camera perception

YOLO segmentation processes both angled cameras. Their detections are merged into one UDP message.

  • Shared bearings: Camera intrinsics and toe angles map detections into a common forward-facing view.
  • Target selection: Confidence, range-normalized mask area, bearing, and arena-cell ownership filter candidate objects.

normalized area = mask area × (range / reference range)²

Sources: Dual-camera inference · Detection-to-decision interface

03 Collection and route planning

The robot follows a fixed sweep route. Live detections determine when it collects an object.

  • Basket constraint: The passive basket holds three objects. Forward motion captures; reverse motion can release the load.
  • Delivery behavior: A full basket interrupts the sweep. The robot returns to deposit its objects.
  • Motion constraints: Alignment and return maneuvers must account for the loaded basket.

Sources: Robot and competition setup

04 Localization and motion control

LiDAR wall fitting estimates pose. Integrated IMU yaw terminates calibrated turn pulses.

  • Lateral motion: LiDAR feedback corrects strafe motion. The timed alternative was disabled after calibration errors.
  • Braking: Stops use calibrated reverse-braking pulses. Cruise speed stays within the measured braking range.

Sources: Motion primitives and measured limits · Braking implementation

05 On-device checks

Inference speed and robot speed determine the observation window for each target.

  • Latency: Benchmark candidate models on the Jetson. Set detection gates for the available inference frames.
  • Camera reliability: Check for frozen streams. Compare raw camera frames with motion logs during tuning.

Sources: On-device latency benchmark · Field tuning
