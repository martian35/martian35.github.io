Multimodal Scene Reordering

SNU AI Challenge · GeekSeek · 2026 · 8th Place

Recover the chronological order of four shuffled images using a vision-language model.

CodeChallenge

Task

Given a sentence and four shuffled frames, predict the chronological rank of each input image.

  • Valid ordering: Use each image exactly once in the predicted sequence.
  • Input-order sensitivity: Align predictions from different image arrangements before combining them.

My contribution

Member of Team GeekSeek in the 2026 SNU AI Challenge. The method and results below describe our team submission.

Temporal ordering method

1. Structured readouts from one model pass

Adapt Qwen3.5-27B with language LoRA. Append ten readout positions after the sentence and four images.

  • Pairwise order: Six readouts score which image comes earlier in each image pair.
  • Chronological slots: Four readouts score the image identity at each position.
  • Output interface: Read frame-label digit logits from the frozen language-model head instead of generating an answer string.

2. Score all valid chronological orders

Enumerate the 24 possible permutations and select the highest-scoring order.

  • Slot score: Sum the log-probabilities of the image assigned to each chronological slot.
  • Pair score: Use the difference between the two frame-label logits. Add or subtract it according to the candidate’s pair order.
  • Rank conversion: Invert the selected image sequence to produce the per-input ranks required by the competition.

order score = slot log-probability + signed pairwise agreement

3. Align predictions across four input arrangements

Evaluate the same sample under four image orderings before decoding.

  • Image identity: Remap slot logits to the original image labels.
  • Pair orientation: Remap pair identities and flip the signed score when a pair’s display order is reversed.
  • Aggregation: Average the aligned slot and pair logits, then run the same 24-permutation decoder.

4. Temporal supervision during fine-tuning

Continue from the language adapter with temporal-gap and ranking objectives.

  • Gap target: Predict the absolute chronological separation of each image pair. This auxiliary head is used only during training.
  • Hard negatives: Compare the true sequence against adjacent swaps, a high-scoring medium-distance order, and full reversal.
  • Staged update: Train the gap head first with the adapter frozen, then jointly fine-tune at a smaller adapter learning rate.

5. One averaged language adapter

Average nine language-LoRA snapshots from the same training trajectory.

  • Parameter mean: Average LoRA A/B tensors on the CPU in float32 and cast them back to the stored dtype.
  • Inference model: Use one averaged adapter with the frozen base model. The training-only gap head is excluded.
  • Compute: Parameter averaging adds no extra forward passes; Random4 still evaluates four input arrangements.
